# Intraday Automation Project

## Steps:

1. Replace `path_to_chromedriver` in IntradayBot.java with actual path to your chromedriver.exe
2. Replace `YOUR_BOT_TOKEN` and `YOUR_CHAT_ID` with your Telegram bot details
3. Build project using:
   mvn clean install
4. Run project using:
   mvn exec:java -Dexec.mainClass="com.automation.IntradayBotManual"
